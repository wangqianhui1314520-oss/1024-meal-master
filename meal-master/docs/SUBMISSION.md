## 精简版（约 150 字，适合提交表单）

干饭指挥官是一个 WorkBuddy 用餐 Skill：输入人数、预算和饮食偏好（如「6 个人、150 块、2 人不吃辣」），立即产出一桌可执行的搭配方案——每人一份主食+饮品、小食补齐、分享装收尾，总价压线不超预算，且每一项选择都附带依据（为什么是这个、为什么不是那个）。官方题实测 ¥149.4/150，预算利用率 99.6%。零依赖、确定性输出，评委现场点一单即出结果。

## 完整版

### 做什么

把「今天吃什么」这个模糊问题，变成一张**可执行、不超预算、每项有依据**的桌单。

给定四个输入——人数、总预算、不吃辣人数、素食人数——引擎在毫秒级完成：

1. **分组**：按饮食偏好拆成「无辣不欢 / 不吃辣 / 素食」，硬约束过滤（不吃辣组绝不出现辣堡，素食组绝不出现肉）；
2. **主食**：每组选「饱腹度最高中价格最低」的套餐；
3. **预算修复**：全桌超支时，按「让位最多」原则把整组主食降级到红区 1+1 组合，循环直到可行；
4. **补齐**：缺饮品补饮品、缺小食补招牌小食（中薯条优先）；
5. **收尾**：结余先买分享装（4 人以上）撑氛围，再 cheapest-first 买甜品；
6. **记账**：全程不击穿预算，每一次降级/切换都写进「引擎决策记录」。

### 官方题实测（评委同款输入）

输入：**6 人 · 预算 ¥150 · 2 人不吃辣**，输出：

| 人群 | 餐品 | 数量 | 小计 |
|---|---|---|---|
| 无辣不欢 · 4 人 | 麦辣鸡腿堡三件套（券后） | ×4 | ¥91.6 |
| 不吃辣 · 2 人 | 1+1 随心配（麦香鸡堡+中可口可乐） | ×2 | ¥25.8 |
| 不吃辣 · 2 人 | 中薯条 | ×2 | ¥26 |
| 全桌共享 | 圆筒冰淇淋 | ×1 | ¥6 |

**合计 ¥149.4 / ¥150 · 结余 ¥0.6 · 预算利用率 99.6%**

关键决策（引擎自动生成，随桌单输出）：

- 麦辣三件套券后 ¥22.9（原价 ¥39.5），是全菜单最低的「堡+薯+饮料」组合，4 位无辣不欢直接用；
- 不吃辣组最便宜的完整套餐需 ¥33.5/人，会击穿全桌预算 → 切换 ¥12.9 红区 1+1 组合保底（有堡有饮料），把预算让给小食；
- 该组合不含小食 → 补中薯条，全桌人人有薯；
- 结余 ¥6.6 → 加 1 个圆筒收尾。

### 评委现场点单路径

```bash
python scripts/plan_meal.py --demo      # 官方题
python scripts/plan_meal.py --people 8 --budget 300 --no-spicy 3 --vegetarian 1   # 任意组合
```

Python 3.8+ 标准库，零安装；也可在 WorkBuddy 任意对话中用自然语言触发本 Skill。

### 亮点

| 亮点 | 说明 |
|---|---|
| 可解释 | 每一项选择都带依据；降级决策自动记录——「钱花得明白」是核心价值 |
| 硬约束保证 | 不吃辣/素食零违规；总价 ≤ 预算（除显式警告的不可行场景） |
